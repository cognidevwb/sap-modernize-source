# Enterprise SAP control-tower source

A substantial enterprise reference sample extending the original SAP modernization fixture. Includes an executable CAP business core, native HANA analytics, ABAP repository objects and CDS/OData read services, BTP descriptors, Fiori elements, and Cloud ALM integration designs.

Start with `docs/ARCHITECTURE.md`, then `srv/lib/order-workflow.js`, `srv/lib/finance.js`, and `hana/src/`. Run `npm test` and `npm run build` in this folder. See `docs/OPERATIONS.md` for deployment boundaries and validation.
